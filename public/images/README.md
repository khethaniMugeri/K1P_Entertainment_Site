# Images go here

Drop your real photos into this folder (and the sub-folders below). The pages
reference these exact paths, so just match the file names when you add a photo.

Expected folders/files as the site grows:

- `og-image.jpg` — the social-share preview image (1200x630). Shows when a link
  to the site is pasted into WhatsApp, Facebook or Instagram. Put a bold
  black/red K1P image here.
- `logo/` — the K1P logo and the Piano Valley logo
- `team/` — about-page people, e.g. `team/ceo.jpg`, `team/cfo.jpg`
- `equipment/` — hire items, e.g. `equipment/sound-system.jpg`
- `artists/` — artist/DJ photos, e.g. `artists/artist-1.jpg`

Anything in this `public/` folder is served as-is, so an image at
`public/images/equipment/sound-system.jpg` is used in code as
`/images/equipment/sound-system.jpg`.
